# DART Robot Control Programs

This repository contains control programs for the DART robot, a four-wheeled robot equipped with sensors (sonars, odometers, inertial navigation unit, lidar) and actuators (motors, 7-segment display). These programs are designed to control and interact with the robot for autonomous navigation and experimentation.

## Programs

- **`measure_inertia.py`**: Measures the inertia of the DART robot by analyzing its stopping behavior after movement.
